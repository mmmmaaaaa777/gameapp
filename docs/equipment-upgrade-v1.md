# Equipment Upgrade v1

## Scope

- 装備強化は Lv1〜Lv5。
- 作成直後の装備は Lv1。
- 既存データにLv情報がない装備は Lv1 として扱う。
- 訓練用装備や初期装備は装備定義に含めず、強化対象にしない。
- v3.1.2 の `DAMAGE_CONSTANT = 30` を使うダメージ計算式は変更しない。

## Upgrade Cost

| 強化 | 魔力の欠片 | コイン |
| --- | ---: | ---: |
| Lv1 -> Lv2 | 1 | 50 |
| Lv2 -> Lv3 | 2 | 100 |
| Lv3 -> Lv4 | 3 | 150 |
| Lv4 -> Lv5 | 5 | 250 |

## Multipliers

| Lv | 倍率 |
| --- | ---: |
| Lv1 | 1.00 |
| Lv2 | 1.15 |
| Lv3 | 1.30 |
| Lv4 | 1.45 |
| Lv5 | 1.60 |

小数は四捨五入する。

## Rebirth

- 武器転生時は転生元のLvを転生先へ引き継ぐ。
- 転生元のLv記録は削除する。
- 転生元にLv情報がない場合は Lv1 として扱う。
